# Projeto Aplicado I - Entrega 02

**Tema:** Modelagem e Implementação de Banco de Dados  
**Empresa parceira:** Schulz S.A.  
**Banco de dados:** SQLite

## Arquivos

- `01_estrutura.md` - modelo conceitual simplificado e justificativa da organização dos dados.
- `02_dicionario.md` - dicionário de dados com os campos, tipos e descrições.
- `03_banco.sql` - script DDL para criação das tabelas no SQLite.
- `04_testes.sql` - consultas utilizadas para testar o banco de dados e seus relacionamentos.
- `sistema.py` - script Python que cria, popula, valida e consulta o banco.
- `calibracao.db` - arquivo do banco de dados SQLite gerado pelo sistema.
- `relatorio_projeto.pdf` - relatório explicativo do projeto.

## Como executar

É necessário ter o Python 3 instalado.

No VS Code, abra a pasta do projeto e execute no terminal:

```bash
python sistema.py
